## 当前需要用户选择

高速套环在精确对准和垂直稳定后仍会在原生 release 后发生突变：一个案例环的姿态误差从约 0.0063 rad，在首个 50 ms 变为约 0.2216 rad，再到约 0.9387 rad。公开相机画面与 TRAIN 标签审计均已保存；标签未输入控制器。

原生任务与通用 backend 的顺序是先 release() 解除 PyRep 挂接，再 actuate(OPEN)。已准备独立候选 `our_mani/executor_release_order_proposal_20261113_v19`，先逐步张开手指，实际开合完成后再调用原始 release()。这不修改 API 实现或 Task.success()，但改变挂接存续时机，属于不同抓取语义，必须单独报告，不能直接作为原始 benchmark 成绩。

4 个种子、两种顺序共 8 个成对案例已准备并通过 --help 预检；尚未启动 Native。异步问题已询问用户：保留原生释放语义继续修控制与感知，还是允许单独实验新顺序并保留原生对照。不要把未回复当批准，不要擅自运行新顺序。

候选默认值 `native_detach_before_open` 委托旧实现；`open_fingers_then_native_release` 才改变顺序。所有旧模型、方块入口与运行默认入口保留。
