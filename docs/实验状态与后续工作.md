## 当前诊断重点

- 释放前的实际 TCP 位置／姿态误差是否来自电机跟踪、抓取坐标转换或接触阻挡。
- 原生 release 与手指开夹的时机如何影响杯／环的接触与姿态。
- 放置失败后回到抓取阶段的恢复路径为何触发硬件运动学偏差保护。
- 目标刷新修复是否在同种子回归中持续生效；不能仅以门控次数下降认定任务成功。

不要把 60 秒预算用完一概解释为预算过小。当前有明确阶段停滞和释放失败，继续放宽时限不能替代修复。
