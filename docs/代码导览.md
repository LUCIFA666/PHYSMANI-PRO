# 关键代码导览

## 两条模型路线

方块已完成的路线：

```text
公开 RGB-D、相机标定、机器人状态
  → 当前目标位置感知
  → GRU / SimNorm context 运动预测
  → Transformer 候选 TCP 位姿与时刻
  → MPC 与执行响应模型
  → 持续参考执行器，每次最多两步实际 50 ms
  → 原生 held 反馈及 Task.success 首次成功锁存
```

| 模块 | 入口／作用 |
|---|---|
| `cube_full_reuse_20261112_v1` | 已完成的全部 TRAIN 来源复用训练和完整 VAL/TEST |
| `cube_motion_residual_20261104_v1` | 运动残差模型、加载合同与运行时 |
| `cube_matched_candidate_20261104_v1` | 候选动作模型；候选槽位不能当时间序列 |
| `cube_native_contact_feedback_live_20261104_v1` | Native held 反馈与当前闭环 |
| `perception_repair_20261111_v1` | 感知失测处理与可见性修复 |
| `highspeed_control_20261111_v1` | 高速控制的集成版本 |

非方块模型路线位于 `multitask_executor_cycle_20261112_v1` 及后续版本：冻结视觉骨干、任务表示、world TCP command head。当前执行器修复通过 TRAIN 专家目标隔离控制问题，**并没有重训这条路线**。不能把它与方块模型共用一个已训练语言／阶段头来描述。
