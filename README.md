**本仓库不包含模型权重、数据集、数值缓存、仿真二进制或原始运行日志。** 原工程中的继承关系和导入路径保持原样；历史版本并不代表全部已采用。

## 核心单元测试

在已安装 PyTorch、NumPy、SciPy、OSQP、h5py 的 Python 环境中：

```bash
python -B tools/run_core_tests.py
python -B tools/check_export.py
```

这两个入口不启动 Native，不训练模型。完整历史测试库还包含其他实验的专用依赖，不把全库 discovery 当成默认验证入口。

无权重快照的核心集合为 178 项，其中 2 项原机器产物集成检查明确跳过；其余 176 项实际运行。原工程 178 项全部通过的历史记录另保留，不将它冒充本次独立目录的结果。恢复对应本地产物后可使用 `--with-local-artifacts` 运行全部集合。

原生复现还需要外部 PhysMani、RLBench、PyRep、CoppeliaSim、数据和相应权重；详细前置条件见 [复现与环境](docs/复现与环境.md)。
